Git beyond VS Code

VS Code is only one way of using Git/GitHub. The most common alternatives are the following:

  1. Using a Graphical Interface such as Git Desktop allows you to use Git without using the command line, and without being constrained with a specific IDE. The different Git commands can be launched directly in the software.
  2. Using the terminal: git can be typically used directly with a command line interface (CLI). It might seem complicated, but it's really not that hard, and many software engineers use git this way. You can learn more starting from this video tutorial
